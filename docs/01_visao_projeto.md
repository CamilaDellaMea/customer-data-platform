# Visão do Projeto

## Customer Data Platform

Este projeto tem como objetivo construir uma plataforma de dados completa, simulando um ambiente empresarial com múltiplas fontes de dados.

A plataforma deverá ser capaz de:

- receber dados de diferentes fontes;
- processar dados em lote e continuamente;
- manter histórico dos dados;
- tratar e aplicar regras de negócio;
- permitir análises de diferentes períodos;
- disponibilizar dados para dashboards no Power BI;
- aplicar Machine Learning para previsões;
- permitir consultas aos dados utilizando Inteligência Artificial.

## Cenário

O projeto simulará uma empresa de e-commerce com operações de vendas, clientes, produtos, marketing e financeiro.

Os dados serão provenientes de diferentes sistemas, formatos e frequências de atualização.

## Objetivo técnico

Construir uma arquitetura de dados limpa, organizada, escalável, rastreável e documentada, utilizando boas práticas de Engenharia de Dados, Analytics Engineering, Machine Learning e desenvolvimento de software.
